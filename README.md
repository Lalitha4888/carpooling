# carpooling
# 🚗 Carpooling App

A full-stack Carpooling web application built with **Python FastAPI (Backend)** and **Flask (Frontend)**. Users can register, log in, and submit ride requests. Drivers can view, accept, or reject ride requests. The app supports role-based dashboards and ride management features.

---

## 🔧 Technologies Used

### Backend (FastAPI)
- FastAPI
- PostgreSQL (via psycopg2)
- Uvicorn
- Pydantic

### Frontend (Flask)
- Flask (session, routing)
- Jinja2 templating
- HTML/CSS (via templates)
- Axios-like HTTP with `requests` module
